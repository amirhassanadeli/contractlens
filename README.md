## 📖 Overview

**ContractLens** is a production-ready, containerized RAG (Retrieval-Augmented Generation) API designed to parse, index, and analyze complex legal contracts in PDF format. 

The system enables precise question answering over uploaded agreements with **zero legal hallucination**, providing **traceable citations** (page numbers and exact excerpts) for every response generated by local LLMs.

---

## 🌟 Key Features

- **Isolated Document Ingestion:** Automated text extraction, multilingual (Persian/English) semantic chunking, and isolated vector indexing per contract.
- **Explainable RAG with Citations:** Every answer returns a verifiable `sources` payload detailing the exact `page`, `filename`, and contextual `excerpt`.
- **Conversational Workflows:** Multi-turn chat sessions bound to individual contract documents.
- **Feedback & Regeneration Loop:** Built-in endpoints for rating responses (`liked: true/false`) and triggering contextual re-generation (`regenerate`).
- **Interactive Swagger Documentation:** Fully mapped with OpenAPI 3.0 via `drf-spectacular`.
- **Fully Containerized & Self-Hosted:** Orchestrated via Docker Compose with local LLM integration (Ollama) and persistent ChromaDB storage.

---

## 🛠️ Tech Stack

| Layer | Technology |
| :--- | :--- |
| **Backend Framework** | Django 5.x, Django REST Framework (DRF) |
| **API Documentation** | OpenAPI 3.0 via `drf-spectacular` (Swagger UI) |
| **RAG Orchestration** | LangChain, Custom Vector Ingestion Pipelines |
| **Vector Database** | ChromaDB (Persistent Vector Store) |
| **LLM & Embeddings** | Ollama (`qwen2.5:7b`, `nomic-embed-text` or compatible models) |
| **PDF Processing** | PyPDF / pdfplumber |
| **Infrastructure** | Docker, Docker Compose, Nginx Reverse Proxy |

## 📖 API Endpoints Reference

All endpoints can be directly executed through the [Swagger Documentation](https://api.amirhassanadeli.com/contracts/api/docs/).

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/api/contracts/` | Upload and vectorize a new PDF contract |
| `GET` | `/api/contracts/` | List all processed contracts |
| `GET` | `/api/contracts/{id}/` | Retrieve contract metadata and extraction status |
| `POST` | `/api/conversations/` | Create a conversation session for a contract |
| `GET` | `/api/conversations/{id}/messages/` | Retrieve message history and attached citations |
| `POST` | `/api/conversations/{id}/messages/` | Send a question & receive grounded RAG answer |
| `PATCH` | `/api/messages/{id}/feedback/` | Submit User Feedback (`liked: true/false`) |
| `POST` | `/api/messages/{id}/regenerate/` | Re-synthesize an assistant answer |
